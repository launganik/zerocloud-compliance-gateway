# Questions to ask the customer

> Demo knowledge base: illustrative templates for the hackathon, not official Forto policy.

## Possible dual-use goods

Ask the shipper for: an end-use statement naming the end user and the intended civilian use; the export licence number, or written confirmation that no licence is required; and the exact technical classification of the goods if known.

## Missing or unclear HS codes

Ask the shipper to confirm the HS code for every goods line. Without an HS code the goods cannot be checked against the control list, so the booking stays held.

## Technical specification sheets

Ask whether the specification sheet is needed for transport at all. If it is not needed, the shipper should send the booking without it. If it is needed, it stays on-prem until the case is approved.

## Example message

"Before we can confirm your booking, we need an end-use statement for the goods and either the export licence number or a confirmation that no licence is required. Please also confirm the HS code for each item."
